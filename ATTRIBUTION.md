## `assets/f15-blueprint.svg`

A modified version of **"McDonnell F-15A DraftSight"** by **Kaboldy**.

- **Source:** <https://commons.wikimedia.org/wiki/File:McDonnell_F-15A_DraftSight.svg>
- **License:** [Creative Commons Attribution-ShareAlike 4.0 International][by-sa]
  (CC BY-SA 4.0)
- **Original:** a McDonnell-Douglas F-15A three-view technical drawing, uploaded
  7 February 2015.

**Modified.** The following changes were made to produce
`assets/f15-blueprint.svg`:

- the white background rectangle was removed, so the drawing sits on a dark page;
- the black line art was recoloured to `#7ee787` (green);
- stroke widths were increased so hairline detail survives downscaling;
- Inkscape metadata, `<defs>` editing aids and unused namespace declarations were
  stripped, reducing the file from 649 KB to 467 KB;
- fixed physical dimensions were replaced with a responsive `viewBox`.

These changes are mechanical and decorative: the geometry, proportions and subject
of the drawing are unaltered.

## `assets/f15-top.svg`

A top-down (planform) drawing of an **F-15 Eagle**, derived from `assets/F15jet.svg`
which was supplied locally by the repository owner.

- **Provenance:** unconfirmed. The source file carried no author, license or source
  metadata, and it does not match any F-15 SVG located on Wikimedia Commons.
- **Modifications:** editor metadata and namespace cruft stripped; fixed dimensions
  replaced with a responsive `viewBox`. Geometry and shading are unchanged.
- **License:** unknown, pending confirmation of the original source.

If you are the rights holder for the original and want it credited differently or
removed, please open an issue.

## Generated assets

The following files are generated by the scripts in `scripts/` and contain only
original work — no third-party content:

| File | Generator |
| --- | --- |
| `assets/banner.svg` | `scripts/generate-assets.mjs` |
| `assets/divider.svg` | `scripts/generate-assets.mjs` |
| `assets/avatar-ring.svg` | `scripts/generate-assets.mjs` |

The banner embeds a small F-15 silhouette drawn from the vendored Font Awesome
glyph geometry described above.

---

## Rebuilding

```
node scripts/generate-assets.mjs      # banner, divider, avatar ring
node scripts/build-jet-assets.mjs     # f15-blueprint, f15-top, jet-glyph
```

Both scripts are dependency-free and read their settings from
`scripts/config.json`.
